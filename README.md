# Meg Love Pet — novo site

Esta é uma primeira versão totalmente nova e responsiva.

## O que já foi resolvido
- Tipografia mais elegante: Cormorant Garamond + Montserrat.
- Bordas, cartões e detalhes em estilo sofisticado.
- Galeria em formato menor e proporcional.
- Clique em qualquer foto da galeria para abrir em tamanho grande.
- Galeria preparada para pets, produtos, serviços, novidades e espaço.
- Comida para pássaros, brinquedos, roupinhas e acessórios com imagem.
- Pacotes usando “A partir de”.
- Instagram, Facebook e TikTok configurados.
- Avaliações organizadas em cartões.

## Importante sobre edição
O site estático do GitHub não consegue gravar alterações em um banco de dados apenas com HTML. A próxima etapa pode transformar a galeria e avaliações em uma área de edição realmente prática pelo celular, usando um CMS ou outra solução de armazenamento.

As imagens desta primeira versão são imagens de demonstração. Elas devem ser substituídas pelas fotos reais da Meg Love Pet antes da publicação definitiva.
